
Frontend dashboard for the SparkApi built in TypsScript with React and Vite. Tanstack Query is used for buffering and querying. Styling with SASS and Charts.js for infographics.
I used Radix Primitives for component library because they come unstyled and are easy to customize.

The main focus on the internship was on the backend so the frontend is very basic. But I still think it does a great job in displaying and manipulating the data.
Loads of improvement can be made though!
